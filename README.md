# StudHub — Telegram Mini App (Quizizz + Маркетплейс)

## Что уже готово (Этап 0-5)

- Структура проекта: бот (aiogram3) + API (FastAPI) + Mini App (HTML/JS) в одном процессе.
- Категории маркетплейса теперь: **Все / Учебное / Товары** (услуги как отдельная
  категория убраны — учебные услуги и материалы объединены в «Учебное»).
- Ряд Все/Учебное/Товары + иконка фильтра — в одну строку, компактно.
- У категории «Учебное» есть примеры подкатегорий: Quizizz, СРС, Реферат, Доклад,
  Шпаргалки, Сканер, Курсовая работа, Дипломная работа, Презентация, Конспект,
  Лабораторная работа. У «Товары»: Учебники, Электроника, Одежда, Мебель, Канцелярия,
  Спортивные товары, Прочее. Списки заданы в `SUBCATEGORY_EXAMPLES` (`database/crud.py`)
  — можно редактировать без миграций.
- Фильтр в разделе «Категории» — универсальный: подстраивается под выбранную
  категорию. Для «Товары» академические поля (курс/группа/факультет/кафедра/предмет)
  скрываются, остаётся только «Тип» (подкатегория). Для «Учебное» и «Все» показаны все поля.
- Каждое поле фильтра открывает попап автокомплита (поиск сверху, список снизу).
  Для подкатегории список подмешивает готовые примеры даже при пустой БД
  (`GET /api/marketplace/filter-options/{field}?category=...&q=...`).
- В разделе «Разместить» — то же самое: после выбора Учебное/Товар показываются чипы
  с примерами подкатегорий (можно выбрать один клик или вписать свой вариант), а
  академические поля скрыты для категории «Товары».
- Раздел «Заказы»: переключатель сверху («Мои заказы» / «Мои объявления»). Карточка
  заказа — номер, название, предмет/курс/факультет/кафедра, цена, статус. Отмена
  заказа в течение часа после создания.
- Оплата: клиент сразу получает сообщение с реквизитами Kaspi; админ — уведомление
  с кнопками ✅/❌ сразу на первом сообщении. Отказ — с указанием причины клиенту.
- Mini App: 5 разделов внизу, однотонные SVG-иконки, единый градиент шапки/меню.
- Языковой попап: English, Русский, Қазақша, Türkmençe.
- Профиль: аватар из Telegram, привязка телефона с автообновлением.

## Чего пока нет (следующие этапы)

- Пункты меню профиля («Настройки», «Уведомления», «FAQ», «Поддержка») — заглушки.
- Миграции (Alembic) — при смене схемы модели проще пересоздать `db/app.db`.
- Автонапоминания админу о горящих дедлайнах custom-заказов.
- Постоянное хранение на Render требует Persistent Disk или внешнюю Postgres.

## ⚠️ Важно при обновлении на проде

Категория `services` заменена на `study`, добавлено поле `subcategory` у объявлений.
Если БД не пересоздаётся автоматически на каждом деплое — удалите старый файл
`db/app.db` после обновления кода, иначе приложение может упасть на несовпадении схемы.


## Изменения в разделе «Разместить» (Этап 0-6)

- Плитки категорий (Учебное/Товары) уменьшены — теперь такие же компактные пилюли,
  как в разделе «Категории».
- Все поля (Тип, Курс, Группа, Факультет, Кафедра, Предмет) теперь **только выбор**,
  без свободного ввода — открывают тот же попап автокомплита, что и в фильтрах
  «Категорий». Для каждого поля гарантированно доступен вариант «Прочее», даже если
  в базе ещё нет ни одного объявления (реализовано в `crud.search_listing_filter_options`).
- Поле «Контакт» стало нередактируемым (`readonly`) — подставляется автоматически
  из Telegram-профиля (`@username`, либо имя, если username не задан).
- После отправки объявления на модерацию клиент получает подтверждающее сообщение
  от бота (`notify_client_listing_submitted`).
- После решения администратора (✅/❌) сообщение с кнопками в админ-чате удаляется
  (или, если удалить нельзя, с него снимаются кнопки) — повторное нажатие невозможно.

## Запуск локально

```bash
cd Quizezz_bot
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# заполните BOT_TOKEN (от @BotFather), ADMIN_CHAT_ID, KASPI_PHONE, KASPI_NAME

uvicorn api.main:app --reload --port 8000
```

Бот и API стартуют в одном процессе (бот поллингом — фоновой задачей внутри FastAPI).

## Чтобы открыть Mini App из Telegram

Telegram требует HTTPS-адрес для Web App. Для локальной разработки:

```bash
# в отдельном терминале
ngrok http 8000
```

Скопируйте выданный `https://...ngrok-free.app` в `.env`:
```
WEBAPP_URL=https://xxxx.ngrok-free.app/webapp/index.html
```
Перезапустите `uvicorn`, затем откройте бота в Telegram и нажмите /start.

## Как узнать ADMIN_CHAT_ID

Напишите боту `@userinfobot` — он покажет ваш `id`. Для группы админов —
добавьте бота в группу и используйте отрицательный ID группы.

## Структура проекта

```
Quizezz_bot/
├── api/                # FastAPI: REST для Mini App
│   ├── main.py
│   ├── schemas.py
│   └── routers/
│       ├── quiz.py
│       └── marketplace.py
├── bot/                # aiogram 3
│   ├── loader.py       # общий Bot/Dispatcher
│   ├── main.py         # регистрация роутеров, запуск polling
│   ├── notify.py       # уведомления админу
│   └── handlers/
│       ├── start.py
│       ├── payments.py # приём чеков от студентов
│       └── admin.py    # подтверждение оплат, модерация, /complete
├── database/           # SQLAlchemy модели + CRUD
├── webapp/             # Mini App (без сборки, чистый HTML/JS)
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
├── db/                 # тут появится app.db (SQLite)
├── config.py
├── requirements.txt
└── .env.example
```

## Деплой (когда дойдём)

Проще всего — VPS (Timeweb/Selectel/DO) + Nginx + systemd, или Railway/Render
для быстрого MVP-хостинга. Тогда `WEBAPP_URL` и `API_BASE_URL` укажут на
реальный домен вместо ngrok.
