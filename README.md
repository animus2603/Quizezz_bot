# StudHub — Telegram Mini App (Quizizz + Маркетплейс)

## Что уже готово (Этап 0-4)

- Структура проекта: бот (aiogram3) + API (FastAPI) + Mini App (HTML/JS) в одном процессе.
- Категория «Реклама» полностью убрана — в маркетплейсе остались только Учебное и Товары
  (бывшая категория «Услуги» переименована в «Учебное», `services` → `study`).
- Каталог тестов и объявления теперь несут академические атрибуты: предмет, курс,
  факультет, кафедра (+ группа у объявлений).
- Категории в Mini App показаны в один ряд компактными кнопками-пилюлями
  (Все / Учебное / Товары) + маленькая круглая кнопка «Фильтр» рядом, вместо
  прежних крупных плиток 3-в-ряд.
- Под категориями — ряд примеров подкатегорий (поле `subcategory` у объявления):
  для «Учебное» — Quizizz, СРС, Реферат, Доклад, Шпаргалки, Сканирование, Курсовая,
  Другое; для «Товары» — Учебники, Техника, Одежда, Мебель/быт, Канцелярия, Разное.
  Тап по чипу фильтрует ленту по этой подкатегории; тот же выбор подкатегории есть
  и в разделе «Разместить» после выбора Учебное/Товар.
- Панель дополнительных фильтров — универсальная под категорию: для «Учебное»
  показываются все 5 академических полей (курс/группа/факультет/кафедра/предмет),
  для «Товары» — только курс и предмет (остальные не так релевантны для случайных
  вещей). По клику на поле открывается попап автокомплита: сверху поиск, ниже —
  примеры (1–4 курс, популярные предметы) и живой список значений из уже опубликованных
  объявлений (эндпоинт `GET /api/marketplace/filter-options/{field}?q=...`).
- Раздел «Разместить»: сначала выбор категории (Товар/Услуга), остальные поля появляются
  только после выбора; контакт автоподставляется из Telegram-профиля; можно приложить
  файл/фото (по желанию) — загружается через `POST /api/upload`.
- Карточка готового теста показывает: предмет, курс, факультет, кафедра, цена.
- Раздел «Заказы»: переключатель сверху («Мои заказы» / «Мои объявления») вместо двух
  списков подряд. Карточка заказа показывает номер, название, предмет/курс/факультет/
  кафедру, цену и статус. Если с момента создания прошло меньше часа и заказ ещё не
  оплачен — снизу кнопка «Отменить (осталось N мин)» (`POST /api/quiz/order/{id}/cancel`).
- Оплата: клиент сразу получает сообщение с реквизитами Kaspi; админ получает
  уведомление с кнопками ✅/❌ сразу на первом сообщении. Отказ — админ пишет причину,
  она уходит клиенту. Подтверждение — клиенту приходит автоматическое сообщение.
- Mini App: 5 разделов внизу (Главная, Категории, Разместить, Заказы, Профиль),
  однотонные SVG-иконки, шапка и нижнее меню — один градиент.
- Языковой попап: English, Русский, Қазақша, Türkmençe.
- Профиль: аватар из Telegram, привязка телефона через `tg.requestContact()`
  с автообновлением и ручной кнопкой обновить.

## Чего пока нет (следующие этапы)

- Пункты меню профиля («Настройки», «Уведомления», «FAQ», «Поддержка») — заглушки.
- Миграции (Alembic) — при каждом изменении схемы модели проще пересоздать
  `db/app.db`, чем накатывать миграцию вручную (см. предупреждение ниже).
- Автонапоминания админу о горящих дедлайнах custom-заказов.
- Постоянное хранение на Render требует Persistent Disk или внешнюю Postgres —
  иначе и БД, и загруженные файлы обнуляются при каждом деплое/рестарте.

## ⚠️ Важно при обновлении на проде

Модель базы данных снова менялась: значение enum `ListingCategory.services`
переименовано в `study`, и в таблицу `listings` добавлена новая колонка
`subcategory`. Если БД не пересоздаётся автоматически на каждом деплое, удалите
старый файл `db/app.db` после обновления кода — иначе приложение может упасть
на несовпадении схемы. Заодно все объявления, у которых раньше была категория
«Услуги», нужно будет разместить заново — старые записи с этим значением enum
станут невалидны.

## Запуск локально

```bash
cd Quizezz_bot
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# заполните BOT_TOKEN (от @BotFather), ADMIN_CHAT_ID, KASPI_PHONE, KASPI_NAME

uvicorn api.main:app --reload --port 8000
```

Бот и API стартуют в одном процессе (бот поллингом — фоновой задачей внутри FastAPI).

## Чтобы открыть Mini App из Telegram

Telegram требует HTTPS-адрес для Web App. Для локальной разработки:

```bash
# в отдельном терминале
ngrok http 8000
```

Скопируйте выданный `https://...ngrok-free.app` в `.env`:
```
WEBAPP_URL=https://xxxx.ngrok-free.app/webapp/index.html
```
Перезапустите `uvicorn`, затем откройте бота в Telegram и нажмите /start.

## Как узнать ADMIN_CHAT_ID

Напишите боту `@userinfobot` — он покажет ваш `id`. Для группы админов —
добавьте бота в группу и используйте отрицательный ID группы.

## Структура проекта

```
Quizezz_bot/
├── api/                # FastAPI: REST для Mini App
│   ├── main.py
│   ├── schemas.py
│   └── routers/
│       ├── quiz.py
│       └── marketplace.py
├── bot/                # aiogram 3
│   ├── loader.py       # общий Bot/Dispatcher
│   ├── main.py         # регистрация роутеров, запуск polling
│   ├── notify.py       # уведомления админу
│   └── handlers/
│       ├── start.py
│       ├── payments.py # приём чеков от студентов
│       └── admin.py    # подтверждение оплат, модерация, /complete
├── database/           # SQLAlchemy модели + CRUD
├── webapp/             # Mini App (без сборки, чистый HTML/JS)
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
├── db/                 # тут появится app.db (SQLite)
├── config.py
├── requirements.txt
└── .env.example
```

## Деплой (когда дойдём)

Проще всего — VPS (Timeweb/Selectel/DO) + Nginx + systemd, или Railway/Render
для быстрого MVP-хостинга. Тогда `WEBAPP_URL` и `API_BASE_URL` укажут на
реальный домен вместо ngrok.
